特色漁場生態模型 (Coastal vs. Deep Sea)：





🏖️ 沿海漁場 (Coastal Fishery)：環境承載量 2,000 尾、初期魚量 1,000 尾，單船作業成本低（$150/艘/年），因距離近最容易成為各國船隊初期蜂擁捕撈而迅速枯竭的熱區。



🌊 遠洋深海 (Deep Sea Fishery)：環境承載量 4,000 尾、初期魚量 2,500 尾，單船作業成本較高（$250/艘/年），魚源豐沛，是船隊初期資本積累的主力戰場。



⚓ 避風港待命 (Harbor)：每艘船維持待命成本僅 $50/艘/年，不捕魚，用於魚源枯竭時停泊避險。

四國商業漁業船隊多代理人競爭 (4-Fleet Multi-Agent Competition)：





包含玩家與三大風格各異的 AI 競爭對手（阿爾法遠洋：積極擴建造船型、貝塔水產：近海專精省成本型、伽瑪漁業：動態邊際效益平衡型）。



財務模型計算：魚價收購（$20/尾）、新造漁船（$300/艘）、拆船殘值（$250/艘）、銀行存款利息（+8%）與高利貸負債利息（-15%）。
